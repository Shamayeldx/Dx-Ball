🎮 DX Ball Assignment 

You have to make a DX Ball game using OpenGL (C++).

🔹 Main idea
Control a paddle at the bottom
Bounce a ball
Break all the blocks (bricks)
Don’t let the ball fall
🔹 Must include (Core – 20 marks)
Paddle control (keyboard + mouse)
Ball movement & collision
3 lives system
Score, time, lives display
Ball speed increases over time
🔹 Perks (required)

At least 3 power-ups:

Extra life
Faster ball
Wider paddle
🔹 Menu (5 marks)
Start / Resume / Exit
🔹 Pause (5 marks)
Player can pause or exit anytime
🔹 Bonus (optional – 15 marks)
Sound, levels, special powers, better design
