# Dx-Ball
🎮 What you have to build

You need to create a DX Ball game using:

OpenGL (GLUT/freeglut)
C++

It’s a classic arcade game where:

A ball bounces around the screen
You control a paddle at the bottom
There are blocks (bricks) at the top
🕹️ How the game works
The ball keeps moving and bouncing
You must prevent the ball from falling down
Use the paddle to hit the ball upward
The ball breaks the blocks
If all blocks are destroyed → 🎉 You win
If the ball falls → ❌ You lose a life
❤️ Core gameplay features (VERY IMPORTANT – 20 marks)

You must implement:

1. Paddle control
Move paddle using:
Keyboard (← →)
Mouse
2. Ball mechanics
Ball moves and bounces:
Walls
Paddle
Blocks
3. Lives system
Start with 3 lives
Lose one life if ball falls
4. Score & time
Show:
⏱️ Time
🎯 Points
❤️ Remaining lives
5. Increasing difficulty
Ball speed increases over time
🎁 Perks system (MUST include at least 3)

When you hit some blocks, items fall down. If paddle catches them, effects happen.

You must implement at least 3 perks, like:

❤️ Extra life
⚡ Faster ball
📏 Wider paddle
🧾 Menu system (5 marks)

Start game

Exit
(Optional: High score)

Player can:
Pause the game anytime
Exit anytime
